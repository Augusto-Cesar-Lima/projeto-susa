
# Projeto de Interface

## User Flow 
A imagem à seguir apresenta o fluxo do usuário ao acessar a plataforma.
![User flow](img/user-flow.jpg)

## Protótipo de baixa fidelidade

<h3><b>Tela - Cadastro</b></h3>
<p>A tela de cadastro (imagem 1) apresenta campos de formulário para cadastrar um novo usuário a plataforma. Os campos possuem validação para garantir os tipos de dados</p>
  
![Cadastro](img/01%20-%20Cadastrar.jpg)

<h3><b>Tela - Recuperar senha</b></h3>
<p>A tela de recuperar senha (imagem 1) apresenta campos de formulário para redefinir a senha</p>

![Login Recuperar senha](img/01%20-%20Login%20-%20recuperar%20senha.jpg)


<h3><b>Tela - Busca de pacientes</b></h3>
<p>A tela apresenta um campo de busca de pacientes por número de CPF ou número da Carteira Nacional de Saúde (CNS) (imagem 1). Ao terminar uma lista com o paciente consultado aparece, com a possibilidade de acessar os sumários de alta. (imagem 2)</p>
  
![Busca de pacientes](img/02%20-%20Busca.jpg)
![Busca de pacientes](img/02%20-%20Busca%20-%20autocomplete.jpg)

<h3><b>Tela - Lista de Sumários de Alta</b></h3>
<p>A tela apresenta uma lista dos sumários de alta do paciente pesquisado, em formato de "card". É possível paginar entre os sumários de alta caso tenha um grande número de registros (imagem 1). Apresenta também um botão para adicionar um novo sumário de alta se necessário.</p>

![Listagem sumários de alta](img/03%20-%20Lista%20de%20sumários%20de%20alta.jpg)

<h3><b>Tela – Sumário de alta</b></h3>
<p>A tela apresenta os registros do sumário de alta selecionado. Contém as informações obrigatórias pelo Conselho Federal de Medicina (CFM) (imagem 1). Os campos não podem ser alterados, mas possui um botão para adicionar uma nova nota, e/ou observação ao sumário de alta.</p>
  
  ![Sumário de Alta](img/05%20-%20Sumário%20de%20alta.jpg)

<h3><b>Tela – Formulário de Sumário de Alta</b></h3>
<p>A tela de Formulário de Sumário de Alta apresenta campos obrigatórios à serem preenchidos com os dados do paciente, motivo da internação e evolução de quadro clínico (imagem 1).</p>
  
  ![Formulário de Sumário de Alta](img/04%20-%20Formulário%20-%20Sumário%20de%20alta.jpg)
