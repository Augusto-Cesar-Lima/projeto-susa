# Template padrão da Aplicação

O layout padrão do site foi construído com as linguagens de marcação HTML e CSS, e a linguagem de programação JavaScript foi utilizada para a construção dos menus responsivos. Um pequeno ícone de lupa foi gerado utilizando SVG na página de busca.

As páginas terão como elemento padrão uma barra lateral com os dados do médico logado (nome e CRM), além dos elementos de identidade visual citados abaixo:

<ul>
<li>Cores: #000000, #333, #555, #f5f5f5, #C0392B, #1E8449, #d9d9d9, #c0c0c0;</li>
<li>Font-family: Arial, Helvetica, sans-serif</li>
<li>Font-size: 14px, 16px, 24px, 36px. </li>
</ul>
